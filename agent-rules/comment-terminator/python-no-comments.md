# Python comment rules

These rules add to the core rules in `comment-terminator.md`.

## Scope

- `.py` and `.pyi` files: `#` comments and docstrings.
- `pyproject.toml` and `setup.cfg` files: `#` comments and lint or type-check ignore entries.

## Skip

Skip these files. List each one in skips.

- `*_pb2.py`, `*_pb2.pyi`, and `*_pb2_grpc.py`.
- Everything under `__pycache__/`, `.venv/`, `venv/`, `site-packages/`, `build/`, and `dist/`.
- Any file with a `# Generated by` or `@generated` header.

## Walk away

- A docstring on a public module, class, or function of a package that another package consumes. Public means the name has no leading `_` and the package exports it. A docstring on a `_private` name dies. A docstring that restates the name dies.
- A docstring that code reads at runtime: `__doc__`, a Click or Typer command help, an `argparse` description, or a doctest.
- A docstring that is the only statement in its body. Deleting it breaks the syntax. Skip it and list it in skips.
- Formatter directives: `# fmt: off`, `# fmt: on`, `# fmt: skip`, `# isort: skip`, `# isort: off`, and `# isort: on`.
- Tool directives: a shebang, a `# -*- coding: <enc> -*-` line, and PEP 484 type comments such as `# type: int`. A type comment gets a flag on its symbol for an inline annotation.

## Suppressions

Delete these forms:

- `# noqa` and `# noqa: <code>`. A bare `# noqa` hides every rule, so it always dies with a flag.
- `# type: ignore` and `# type: ignore[<code>]`. A bare `# type: ignore` always dies with a flag.
- `# pyright: ignore[<rule>]` and file-level `# pyright: <setting>` lines that weaken checks.
- `# mypy: ignore-errors` and `# mypy: disable-error-code=<code>`.
- `# pylint: disable=<rule>`.
- `# nosec`. It hides a Bandit security finding, so it always dies with a flag.
- `# pragma: no cover`.
- The guilty code in `[tool.ruff.lint]` `ignore` or `per-file-ignores`, in `[tool.mypy]` `disable_error_code` or `ignore_errors`, or in `[flake8]` `ignore` of `setup.cfg`.

Flag only, never edit: `typing.cast(...)` and an `Any` annotation that hides a type error.

Style-only rules survive: `E501` line length, `E203`, the `W` group, the `D` pydocstyle group, the `N` naming group, and the `I` import sort group.

`F401` unused import in an `__init__.py` re-export dies with a flag on the module. The module declares `__all__` or imports with `from x import y as y`.

Correctness and security rules die with a flag. Examples: the `F` Pyflakes group (`F821` undefined name), the `B` Bugbear group, the `S` Bandit group, the `ASYNC` group, mypy `arg-type`, `union-attr`, `attr-defined`, `return-value`, and `override`, and pyright `reportOptionalMemberAccess`.

## Tracing

Use the LSP tool for references and definitions. Fall back to Grep.
