# C# comment rules

These rules add to the core rules in `comment-terminator.md`.

## Scope

- `.cs` files: `//` and `/* */` comments, and `///` XML doc comments.
- `.csproj`, `.props`, and `.targets` files: `<!-- -->` comments and `<NoWarn>` entries.
- `.editorconfig` files: `#` and `;` comments, and `dotnet_diagnostic.<ID>.severity` entries.

## Skip

Skip these files. List each one in skips.

- `*.g.cs`, `*.g.i.cs`, `*.Designer.cs`, `*ModelSnapshot.cs`.
- Any file with an `<auto-generated>` header.
- Everything under `obj/` and `bin/`.

## Walk away

- Non-obvious behavior forced by a P/Invoke signature, COM interop, a framework bug, or a wire format.
- `///` on a `public` or `protected` member of an assembly that another assembly references or that ships as a NuGet package. `<inheritdoc />` on such a member also survives. `///` on an `internal` or `private` member dies. `///` that restates the member name dies.
- Formatter directives: `// @formatter:off` and `// @formatter:on`.
- Tool directives: `#nullable enable`, and the language injection comments `// language=<id>` and `/*lang=<id>*/`.

## Dies

- `#region` and `#endregion` are banners. Both lines die.
- Commented-out code, including commented-out `using` lines and attributes.

## Suppressions

Delete these forms:

- `#pragma warning disable <ID>` and its matching `#pragma warning restore <ID>`.
- `[SuppressMessage(...)]` and `[assembly: SuppressMessage(...)]`.
- `[ExcludeFromCodeCoverage]`.
- `// ReSharper disable <rule>` and `// ReSharper disable once <rule>`.
- `#nullable disable`.
- The guilty ID in a `<NoWarn>` entry. Delete the element when no ID remains.
- `dotnet_diagnostic.<ID>.severity = none` or `= silent` in `.editorconfig`.

Flag only, never edit:

- The null-forgiving `!` operator.
- A cast to `object` or `dynamic` that hides a type error.

Style-only rules survive: `IDE*` formatting rules such as `IDE0055`, StyleCop `SA1xxx` layout and spacing rules, and `CA1707` naming.

Correctness, reliability, and security rules die with a flag. Examples: `CS8600` to `CS8625` nullable warnings, `CS4014` unawaited task, `CS0618` obsolete member, `CA2000` undisposed object, `CA2100` SQL injection, `CA1849` sync-over-async, `CA2007` missing `ConfigureAwait` in a library, `CA5350` and `CA5351` weak cryptography.

## Tracing

Use the Roslyn navigator tools: `find_references`, `find_callers`, `get_symbol_source`, and `get_diagnostics`.
