---
description: Review a pull request against its Skuld card's acceptance criteria
---

Usage: /review-pr <pr_url> <card_name>

Arguments provided: $ARGUMENTS

Parse the arguments above: the first token is the pull request URL (`pr_url`), and the remainder is the Skuld card title (`card_name`).

Review the pull request at `pr_url` using your `review-pr` skill.

The story and its acceptance criteria can be found in Skuld using your Skuld MCP tools, the card titled `card_name`.
